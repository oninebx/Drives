## Objective

Centralise Access Token storage and management within AuthContext, establishing a single source of truth for authentication-related token state across the OIDC and Legacy authentication strategies.

The objective is to eliminate duplicated Access Token storage across Redux and localStorage, and ensure that authentication state and token management are isolated to the currently active strategy and its corresponding Auth0 Tenant.

## Scope

1. Centralise Access Token storage and state management within AuthContext.
2. Establish a unified mechanism for retrieving Access Tokens through the Authentication module, applicable to both OIDC and Legacy strategies.
3. Remove existing Access Token storage and retrieval logic from Redux and localStorage.
4. Ensure that only the currently active authentication strategy and its corresponding Auth0 Tenant can provide a valid Access Token.
5. Ensure that authentication state and tokens associated with the previously active strategy cannot be reused when switching between strategies.
6. Review and refactor other Auth0-related lifecycle management logic to align with the new Authentication architecture.
7. Ensure authentication sessions can be restored after a page refresh without relying on persistent Access Token storage.
8. Ensure existing API integrations and Core Functionalities are not affected.

## Acceptance Criteria

- Access Token is managed centrally within AuthContext for both OIDC and Legacy strategies.
- Application components and API integrations use the unified token retrieval mechanism.
- Access Tokens are no longer stored in Redux or localStorage.
- Only the active strategy can provide an Access Token associated with its configured Auth0 Tenant.
- Switching strategies invalidates the previous strategy's local authentication state and prevents reuse of its Access Token.
- Token renewal, session restoration and logout work correctly for both strategies.
- Existing authentication flows and Core Functionalities are not affected.
- Obsolete token storage and retrieval logic is removed.
